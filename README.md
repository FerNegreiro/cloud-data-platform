\# Cloud Data Platform



End-to-end Cloud Data Platform combining Data Engineering and DevOps practices.



\## Current Architecture



FastAPI → SQLAlchemy → PostgreSQL → Docker



\## Technologies



\- Python

\- FastAPI

\- PostgreSQL

\- SQLAlchemy

\- Docker

\- Docker Compose

\- Git

\- GitHub



\## Features



\- FastAPI REST API

\- PostgreSQL database running in Docker

\- Environment variables for credentials

\- Database health check

\- Docker Compose infrastructure

\- Git version control
